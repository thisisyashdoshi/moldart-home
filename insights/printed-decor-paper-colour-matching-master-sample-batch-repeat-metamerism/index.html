Printed Decor Paper Colour Matching: Master Sample, Batch Repeat, Metamerism

Use this guide when decor paper colour approval needs master sample, batch sample, agreed light source, metamerism check, Delta E if available, and retained sample control.

Use the stated buyer decision to determine the next evidence, sample, document, or RFQ action.

Scope and evidence boundary

Applies to: This guide applies only when decor paper colour approval needs master sample, batch sample, agreed light source, metamerism check, Delta E if available, and retained sample control.

Does not establish: It is buyer guidance, not a product TDS, test report, certificate, or contractual acceptance specification.

Evidence status: Confirm actual values, documents, test methods, sample/lot scope, and acceptance criteria in the approved programme record.

decision flow

Decision flow

Sample approval route: artwork -> master sample -> batch sample -> impregnation trial -> pressed reference -> retained sample.

  1. Freeze artwork and repeat reference
  2. Approve the sample under agreed conditions
  3. Run the agreed process trial
  4. Retain the approved production reference
