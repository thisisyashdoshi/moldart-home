How to specify press plates for wood-panel lamination

A practical specification checklist for technical, procurement and production teams. The goal is a cleaner enquiry and a clearer acceptance basis—not a one-size-fits-all tolerance sheet.

Draft technical guide · acceptance values remain order-specific

A press-plate enquiry is easier to review when the requirement is defined as an acceptance basis, not only as a finish name or nominal thickness. The exact limits depend on the order, application, drawing, material condition, surface requirement and inspection method.

For a cleaner RFQ, define the following five items before commercial comparison.

01
Nominal size

State plate length × width × thickness (L × W × t). If dimensions are drawing-controlled, attach the latest approved revision.

02
Geometry requirements

Specify flatness, parallelism, edge condition or other geometry only where the application actually requires it, together with the relevant measurement points or grid.

03
Surface / finish basis

Name the required finish or provide an approved visual/reference sample. Where quantified surface texture is controlled, define the parameter and evaluation method.

04
Material / coating basis

State the required material grade and condition. If a coating is required, define the coating type and acceptance basis before inspection.

05
Inspection and acceptance basis

Identify what is measured, where it is measured, which instrument is used, whether calibration evidence is required, and how non-conforming results are handled.

What should not be assumed

Press-plate acceptance is not governed by one universal value for roughness, flatness, parallelism, hardness, coating thickness, gloss, defect allowance or service life. Those values must be tied to the exact product/order/process and supporting evidence.

A useful RFQ separates the measurement method from the acceptance value. The method can be standardized; the pass/fail limit still belongs to the exact order unless a validated product standard says otherwise.

Practical RFQ checklist

  • Nominal L × W × t
  • Drawing / revision
  • Required material grade / condition
  • Finish or approved visual reference
  • Surface-texture parameter and evaluation method, if specified
  • Flatness / parallelism / edge requirements, if specified
  • Coating type / thickness basis, if applicable
  • Hardness basis, if applicable
  • Measurement points / grid
  • Instrument / calibration expectations
  • Visual defect disposition
  • Quantity and required delivery basis

Frequently asked questions

Can one tolerance be used for all press plates?

No. Dimensional and geometry limits should follow the exact order, drawing and process requirement.

Is a finish name enough for technical acceptance?

Not always. For controlled applications, use an approved visual reference and, where needed, the exact measured surface parameter and evaluation method.

Should hardness or coating thickness always be specified?

Only when they are relevant to the required material/coating system and supported by an appropriate inspection method.
