# ChatGPT Image Prompts

Use these prompts manually in ChatGPT with the newest image generation available in your subscription. This workflow does not use the OpenAI API and does not require any API key.

After downloading the images from ChatGPT, rename each file to include the slug shown below and place it in `chatgpt-visuals-inbox/`. Then run `npm run images:import`.

## Portal buyer-seller controlled record

Slug: `portal-buyer-seller-record`

Copy this into ChatGPT image generation:

```text
Create a minimal black-and-white B2B industrial website diagram for Moldart. Subject: private buyer-seller trade workspace. Visual structure: left lane Buyer Workspace, center spine Controlled Trade Record, right lane Seller Workspace. Center steps: Requirement, RFQ, Seller Response, Quote, Approval, Order, Payment, Production/QC, Logistics, Documents, Repeat Supply. Style: premium Swiss editorial, white background, thin zinc-gray lines, black typography, strong whitespace, no fake people, no fake factory, no logos except small word MOLDART if useful. Aspect ratio 3:2.
```
