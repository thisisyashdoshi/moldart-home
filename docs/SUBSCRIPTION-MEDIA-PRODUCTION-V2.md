# Moldart Subscription Media Production V2

Status: local draft only; no publication or deployment.

## Objective

Create useful, technically accurate buyer-facing media without exhausting subscriptions on speculative generations. Subscription usage is allocated by capability, and every output must pass identity, geometry, rights, confidentiality and claim checks before integration.

## Product asset rule

Each product page is designed for **three truthful views plus one optional clip**, not five or ten speculative generations:

1. **Identity:** full product or programme view.
2. **Decision detail:** edge, surface, weave, section, finish, joint or handling detail that helps specification.
3. **Application or protection:** verified application, packing or approved sample context.
4. **Optional video:** real footage first; otherwise one Flow camera-motion candidate from an approved real first frame.

A single composite hero may combine the three separately approved photographs in Canva, but original gallery files remain available for zoom/detail. Missing sources produce `SOURCE_REQUIRED`, not synthetic replacement.

## No-waste sequence

1. Approve source identity and rights before upload.
2. Produce one candidate per platform, not a batch.
3. Compare the candidate with the source at 100% crop and reject geometry drift.
4. Use Grok as an independent critique and a human technical reviewer for final approval.
5. Only after one product passes, repeat the same controlled recipe for related products.
6. Generate video only after the corresponding still set is approved.
7. Keep original, prompt, output, hash, subscription, date, reviewer and decision in the media register.

## Acceptance checks

Reject if the output invents geometry, thickness, scale, layer order, machinery, people, readings, documents, facilities, stock, certification, defects or project evidence; changes a material identity; contains pseudo-text; shows impossible gravity/contact; drifts between video frames; or lacks clear rights/provenance.

## Local review integration state

Every use carries a buyer-facing `Representative image` or `Route diagram` label and keeps exact construction, dimensions, acceptance basis and availability subject to RFQ confirmation. This scope extension exists so the eight solution routes can be reviewed visually; it does not approve rights, evidence use or publication.

The public release gate must continue to fail closed outside this noindex review mode. About, QC, facility, packing and defect slots remain source-required until real rights-cleared photography or footage is supplied. No video is integrated because no verified source-grounded output exists.
