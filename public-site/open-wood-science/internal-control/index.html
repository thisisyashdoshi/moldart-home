Internal control dashboard

A lightweight web-control layer for the current Microsoft 365 workflow. It reads SharePoint Lists, highlights screening/assignment risk, and prepares private-copy assignment triggers without directly sharing any document.

Safety boundary: this page never sends reviewer invitations directly and must never share master drafts or parent folders. Assignment creation only stages `OWS_Review_Assignments` with `AccessStatus = Approved - Send Access`; the existing private-copy automation handles access separately.
Stored only in this browser tab session. The API must also have `OWS_ADMIN_TOKEN` configured.
